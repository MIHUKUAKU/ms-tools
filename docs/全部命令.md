# MS 全部命令与刷交易操作

这里把现在的命令和参数都记一下。`<…>` 是必须填的，`[…]` 可以不填，输入时不用带括号。写 `<假人>` 的地方要填在线 Carpet 假人，不能填真人。预设编号建议用正整数，交易链的正负编号另有区别。维度写 `overworld`、`the_nether` 或 `the_end`，坐标和朝向可以按 Tab 补全。

安装器开启 `scriptsAutoload true`，四个脚本设为 `stay_loaded`；进入世界后直接用 `/ms` 显示简要帮助。若自动加载失败，由有权限的管理员检查日志并视情况手动 `/script load` 排错；Java 模组扩展的 `collect` 和 `trade ... keep` 另见下文。普通玩家使用 `/ms` 不需要 OP，但依赖 Scarpet 的 `command_permission=players` 和世界 `carpet.conf` 的 `commandPlayer true`。

参数速查：`x y z` 是假人脚底位置，站在方块中心通常使用 `x.5 / z.5`；`yaw` 是水平朝向，0=南、90=西、±180=北、-90=东；`pitch` 是抬头/低头角度，负数抬头、正数低头、0 水平、±90 垂直。`gt` 是游戏刻，正常 20 TPS 时 20 gt≈1 秒，卡顿时实际等待会更长。`look` 的俯仰补全顺序为 `60、0、-45、-75`，yaw 默认建议假人当前朝向。

最小示例（坐标只是示例，请用 Tab 替换成你的实际位置）：

```text
/ms add 1 alex 100.5 70 100.5 0 0 overworld
/ms list 1
/ms keep 1
/ms run 1
/ms remove 1
```

## 预设与假人

| 命令 | 效果 |
| --- | --- |
| `/ms add <ID> <假人名> <x> <y> <z> <yaw> <pitch> <维度>` | 保存一个假人出生点与朝向；同 ID 不覆盖，先 `remove` 再添加。 |
| `/ms list [ID]` | 不带 ID 列出全部预设，带 ID 查看详情和假人在线状态。 |
| `/ms remove <ID>` | 删除预设，不是清空假人物品。 |
| `/ms bots` | 列出在线假人位置、维度、视角和主手物品。 |
| `/ms create <假人名> [目标玩家]` | 在自己或指定在线玩家位置创建假人。 |
| `/ms send <在线假人> [目标玩家]` | 让在线假人退出再在自己/目标玩家位置重新生成；支持跨维度携货送达。 |
| `/ms run <ID>` | 使用预设假人右键一次，约 4 游戏刻后退出。 |
| `/ms walk <ID>` | 右键一次，等待约 20 游戏刻再退出。 |
| `/ms keep <ID>` | 让预设假人保持在线，不执行右键。 |
| `/ms fight <ID> [攻击间隔]` | 假人连续攻击；默认 14 游戏刻，间隔至少 1。用 `/ms run <ID>` 可让预设假人退出。 |
| `/ms drink <ID>` | 假人持续使用主手物品。用 `/ms run <ID>` 可退出。 |

`run`、`walk`、`keep`、`fight`、`drink` 若对应假人已在线，会使用现有假人；不会强制传送到预设点。`create/send` 操作会改变假人所在位置，请先处理好背包与周围风险。

## 物品、容器与合成

| 命令 | 效果 |
| --- | --- |
| `/ms fetch <在线假人> [目标玩家]` | 假人看向 5 格内容器，取出可装入的物品；不指定目标玩家则留在容器处，指定后尝试返回该玩家。独立脚本也可用 `/fetch …`。 |
| `/ms fetchall <在线假人或预设ID> [目标玩家]` | 在当前位置按四个俯仰角扫描、抓取假人面前容器。 |
| `/ms fetchall <在线假人或预设ID> <l\|r> <距离> [目标玩家]` | 从当前位置起按左/右方向逐列扫描，共 `距离+1` 列；距离为非负整数。动作期间可用 `control … stop` 中止。 |
| `/ms put <在线假人> [箱子ID]` | 不带 ID：将假人主背包物品存入面前 5 格内的容器；带 ID：沿已登记的平坦直线路线去箱子存放。独立脚本也可用 `/put …`。 |
| `/ms put add <箱子ID> [x y z yaw pitch [维度]]` | 不填位置时，记录你当前看向的 5 格内容器和站位/视角；提供坐标时从该站位/朝向追踪容器。已有 ID 不覆盖。 |
| `/ms put list`、`/ms put remove <箱子ID>` | 查看或删除登记的箱子。 |
| `/ms collect <在线假人> [存放箱子ID]` | Java 扩展：以假人主手物品为目标，在假人周围约 `20×4×20` 范围收集可达容器中的匹配物品；可指定完成后投放的 `put` 箱子。主手物品是选择器，不用于收纳。也可用 `/mscollect …`。 |
| `/ms craftbox <在线假人> [材料箱子ID 成品箱子ID]` | 不填箱子时，从假人主背包的材料合成空潜影盒；填两个不同的已登记箱子 ID 时，从材料箱取料并把成品运至另一箱。也可用 `/mscraftbox …`。 |
| `/ms throw <在线假人>` | 丢出假人全部物品：主背包、盔甲栏和副手。独立脚本也可用 `/throw …`。 |
| `/ms clear <在线假人>` | **直接清空**假人主背包 36 格；不丢出、不可撤销，也不清盔甲和副手。 |

`put` 的自动路线要求同一维度、同一平坦高度、直线无缺口/障碍，最大水平距离 100 格；到站会按保存的视角存放。`collect` 和箱子模式 `craftbox` 也使用受限移动逻辑，**不是通用寻路**。存放时若目标是潜影盒，脚本不会把潜影盒再塞进去。大规模执行前请用少量物品试运行。

装盒细节：`fetch` 优先把普通物品放进假人已有潜影盒的空格，保留盒内现有内容；放不下才使用主背包。它不会将潜影盒放进潜影盒。`collect` 若主手是装有物品的潜影盒，会按盒内物品**首次出现顺序**逐种收集，重复种类只算一次；每种物品优先放入假人携带的同类纯净潜影盒，再用空潜影盒，最后才放主背包，不向已有其它物品的盒子混装。来源容器里若有只装该种物品的潜影盒，且假人有空主背包格，会先把同容器散装同类物品尽量填进去，再整盒取走；混装来源盒只取其中目标物，保留盒子及其它内容。`craftbox` 的配方是 **1 箱子 + 2 潜影壳 → 1 空潜影盒**，材料可在假人主背包及其中携带的潜影盒里；箱子模式也能从来源箱及箱内潜影盒取材料，但成品箱本身不能是潜影盒，且假人须有空主背包格运送成品。材料不足或无法安全放置产物时，不消耗该次配方材料。

## 自动交易与交易链

先让假人主手拿着**想买到的物品**作为选择器；背包、携带的潜影盒或绿宝石块中须有足够绿宝石及结果存放空间。`/ms trade` 只匹配村民已解锁的、以绿宝石支付的对应结果交易；单次调用最多执行 512 笔，空间/货币不足会停止。它不会刷新村民交易表；刷交易筛选另见页末。

| 命令 | 效果 |
| --- | --- |
| `/ms trade <在线假人>` | 与假人面前 5 格内村民交易；也可用 `/mstrade <假人>`。 |
| `/ms trade chain add <链ID>` | 正数链：保存玩家当前方块中心站位和视角；负数链：保存准星 8 格内村民的 UUID。`0` 无效。 |
| `/ms trade chain remove <链ID>` | 从正数链移除当前附近位置，或从负数链移除准星所指村民。 |
| `/ms trade chain capture <链ID> [半径]` | 把附近石匠批量捕获到链中，**替换**原链；默认半径 32，范围 1–64，垂直约 ±8。正数链登记石匠工作站前的站位，负数链登记村民 UUID。 |
| `/ms trade chain list [链ID]` | 列出链 ID 或某条链的详细条目。 |
| `/ms trade chain delete <链ID>` | 删除整条链。 |
| `/ms trade <在线假人> <链ID>` | 按链顺序交易。正数链让假人沿保存的平坦站位路线行走；负数链依据已加载村民实体，不作正数链路线行走。 |
| `/ms trade <在线假人> <正数链ID> keep` | 开启按村民工作与补货时间反复交易的保持模式；仅正数位置链可用。该任务状态只在当前服务端运行期间有效。 |
| `/ms trade <在线假人> <正数链ID> keep stop` | 停止该保持模式并让受控假人退出。 |
| `/ms trade <在线假人> <正数链ID> keep report [on\|off]` | 查看/开关保持模式的例行报告，默认关。 |

交易链也可用独立根命令 `/mstrade chain …`。正数链的行走同样受平坦直线路线、障碍和距离限制；先用短路线试验。链定义保存在世界数据中，安装器不会覆盖其 JSON。`keep` 在每天约 **300 gt** 让假人上线，自 **2000 gt** 工作时段检查交易，等待村民原版每天最多两次补货；保存的每个村民均完成两次补货且目标交易售罄后让假人下线，次日再来。例行报告默认静默，可用 `keep report on` 打开；缺绿宝石、无安全空间、路线失败等停止原因仍会提示，不能将静默视为成功。退出世界/重启后要重新开启 `keep`。

## 实时控制、世界规则与危险操作

`<目标>` 可填在线假人名或已有预设 ID，但最终必须解析为**在线假人**。

| 命令 | 效果 |
| --- | --- |
| `/ms control <目标> move <forward\|backward\|left\|right> [格数]` | 按方向移动指定水平距离，默认 1 格，最小 0.1；这是方向控制，不是寻路。 |
| `/ms control <目标> move stop` | 停止当前移动。 |
| `/ms control <目标> look <up\|down\|north\|south\|east\|west>` | 设置视角方向。 |
| `/ms control <目标> look <yaw> <pitch>` | 设置精确视角；yaw 范围 -180 到 180，pitch 范围 -90 到 90。 |
| `/ms control <目标> turn <left\|right\|back>` | 相对当前视角旋转 90°/90°/180°。 |
| `/ms control <目标> stop` | 停止假人动作，并取消当前 `fetchall` 与移动控制。 |
| `/ms phantom [status\|off\|on]` | 查看/关闭/开启自然幻翼生成；改变世界游戏规则。省略参数等于 `status`。 |
| `/ms hardbreak [status\|off\|on]` | 为命令执行者开启/关闭特殊点破；开启后左键点击基岩或末地传送门框架会直接变成空气，**不掉落**。省略参数等于 `status`。该状态不持久化，重开世界默认关闭。 |

## 独立刷交易模组：没有聊天命令

在**本机单人存档**打开村民交易界面后，点「筛选设置」，可设物品（中文名或物品 ID，留空不限）、附魔/药水效果及等级、绿宝石价格上下限、基础价或当前价、等级恰好/至少、额外附魔/效果是否允许，以及一个或多个交易序号。内置「331 钻石镐」「附魔书」「药水箭」预设和中英文名称列表。序号从 1 开始，包含 Visible Traders 的未来等级预览交易；多选时**任意一个**序号符合条件即命中。先选预设与条件，再选序号，最后在主设置页保存。

重新打开村民交易窗口，点「筛选：开始」才会重掷；点「停止」、关闭窗口或切换交易对象会终止。命中后只停下并报告结果，**绝不自动购买**。村民必须绑定工作站且没有交易经验；交易输入格与鼠标持物须为空。高级预览未加载完整时先等候，再重新打开设置。单次最多 10000 次刷新；该上限是安全停止，不保证一定命中。配置存于客户端 `config/trade-target.properties`，MS 安装/交易链数据与其分开。
