# MS 1.7.3 / 刷交易筛选 1.4.2

把之前自己用的假人指令整理出来了，另外把刷交易筛选也放在一起发布。**这两个是分开的模组**，可以只装其中一个。

目前适配 Fabric 26.2 / 26.3，Java 25，Fabric Loader >= 0.19.3。其它 Minecraft 版本没验证，先别直接装。

## 下载哪个

- 不想手动安装：下载 `MS-Tools-1.7.3-Windows-Installer.zip`，完整解压后双击 `installer/Install.cmd`。选择启动器里的 Fabric 版本和存档，前置会自己下载。先退出游戏。
- 自己装 MS：用 `mstrade-1.7.3.jar`，还需要安装包里的四个脚本和 Carpet，光放这个 jar 不够。
- 只装刷交易筛选：用 `trade-target-331-1.4.2.jar`，前置是 Fabric API、Trade Cycling >= 1.0.21、Visible Traders >= 2.5.0。
- 想看或者改源码：下载 `MS-Tools-1.7.3-Source.zip`，解压就是完整项目。它不是能直接装进游戏的包。
- `SHA256SUMS.txt` 是文件校验值。

前置不用卡死某个小版本，但要对应游戏版本。Gugle Carpet Addition 的假人背包界面不是必装的。

## 这次改了什么

- 适配了 26.2 和 26.3 的接口差异。
- 修了交易时绿宝石块拆不够，以及找零和商品抢同一个空格可能导致扣款的问题。
- 真人正在和村民交易时，假人不会抢那个村民。
- 退出世界会清掉后台任务，避免换存档后旧任务继续跑。
- 加了中文命令说明和带备份的安装器。

后台检查和已经完成的实测结果在安装包的 `docs/测试报告.md`，没有继续追加测试，也没有说所有情况都测过。
安装包的 `docs/全部命令.md` 写了全部参数，`docs/安装说明.md` 写了前置、安装和备份的位置。

没有放进我的存档、假人坐标、交易链或者账号配置。
