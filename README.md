我一开始只是想用一个短指令开关和平机，不想每次输入假人名字、坐标和朝向。后来干脆把搬东西、装潜影盒、合成和村民交易也接了进来，现在把自己这套生存工具整理出来分享。

## 选择存档，准备开工

[下载 Windows 安装包](https://github.com/MIHUKUAKU/ms-tools/releases/latest) → 解压 → 双击 `开始安装.cmd` → 选择自己的存档文件夹 → 确认安装。

安装器识别26.2／26.3 Fabric实例，**先检测已有前置，符合要求就保留**；补齐缺失文件，安装工具和四脚本，自动配置所选生存存档。重新进入存档后输入 `/ms`。先在启动器装好Java25与Fabric，并正常启动过一次；安装前退出游戏。需要独立刷交易筛选时，运行 `安装含交易筛选.cmd`。

前置随包提供或从官方来源获取，保留[原作者入口和许可证](installer/前置来源与许可.txt)。已有相关文件先备份；准确支持范围见[安装说明](docs/安装说明.md)和[测试记录](docs/测试报告.md)，不承诺所有前置组合兼容。

v1.7.5 修复 Windows PowerShell 5.1 下的文件校验中断。Windows 测试机已验证三个实际 CMD 入口和存档权限配置；需先有可正常启动的 Java25／Fabric 游戏实例。

**新版本优先在 GitHub 发布。** 不常用论坛可能延后1天至1周同步，请以[GitHub最新版本](https://github.com/MIHUKUAKU/ms-tools/releases/latest)为准。有安装或使用问题，欢迎留言或[提交Issue](https://github.com/MIHUKUAKU/ms-tools/issues)。

### 已装模组，只为另一个存档开启权限

运行 `启用已有存档.cmd`，选择存档。它会检查实例已装好MS与Carpet，再复制四个脚本并自动设置 `commandPlayer true`、`scriptsAutoload true`，保留全部已有模组。普通生存玩家无需OP即可使用 `/ms`。

`开始安装.cmd` 已包含这一步；首次安装只运行它即可，不需要再重复启用。

## 一套工具，两个独立模组

**MS 假人工具**用 `/ms` 控制 Carpet 假人，负责实际操作和购买已有交易。

**Trade Target 刷交易筛选**是另一个模组，在村民交易界面里寻找符合条件的交易，命中就停，**不会自动购买**。可以只装一个，也可以一起装。

## 功能一览

| 功能 | 假人能做什么 |
| --- | --- |
| 取物与扫箱 | 从面前容器取货，也能按左／右方向逐列扫描取物，优先装入携带的潜影盒。 |
| 向玩家送货 | 取货后送到自己或指定在线玩家身边；支持跨维度携货传送。 |
| 自动整理与装盒 | 按目标物品收集；用潜影盒里的物品清单指定多种目标，逐种收集、同类优先装盒，尽量填满同类来源盒后整盒带走。 |
| 存放与潜影盒合成 | 将假人携带物品存入容器；可登记存放点，也能从材料合成空潜影盒并运送成品。 |
| 自动交易与交易链 | 假人购买已有的村民交易，按保存的交易链逐个采购，支持用绿宝石块及潜影盒中的绿宝石支付。 |
| 自动驻留交易 | `keep`按工作时段上线，等待补货后继续交易，完成当日补货采购后退出、次日继续；重开世界后重新启用任务。 |
| 远程机器控制 | 保存假人位置、朝向和操作预设，调用右键操作已有和平机等机器，也可持续攻击或使用主手物品。 |
| 跨维度珍珠回家 | 提前在滞留装置留下自己的珍珠，由假人触发机关，支持跨维度回家；珍珠会加载自身所在区块。 |
| 假人实时控制 | 创建假人、查看状态、移动、调整视角、转向、停止动作，以及物品丢出／清空。 |
| 附加世界工具 | 自然幻翼开关、特殊方块点破开关；具体影响见命令说明。 |
| 独立刷交易筛选 | 另一个仅单人使用的模组：筛物品、附魔／药水效果、价格和交易序号，命中即停。 |

自动移动用于预先整理的平坦通路。详细参数与操作见[全部命令](docs/全部命令.md)。

## 把这些事交给假人

| 你想做的事 | MS 帮你怎么做 |
| --- | --- |
| 一键调用机器旁的假人 | 存好坐标和朝向，用编号 `run` / `walk` / `keep` 调用 |
| 把仓库里的物资带回来 | `fetch` 取面前箱子，`fetchall` 沿箱子逐列扫，`send` 回到指定玩家 |
| 从附近箱子里找指定物品 | `collect` 按主手物品收集，支持从潜影盒里取出，优先同类装盒 |
| 把材料变成打包用的空盒 | `craftbox` 合成潜影盒，材料箱和成品箱可以分开 |
| 让假人跑村民交易所 | `trade` 按主手物品购买，自动拆绿宝石块；交易链 `keep` 等补货再交易 |
| 随时调整假人的位置和视角 | 移动指定格数、抬头低头、转向，完成后看状态反馈 |

还有持续攻击、持续右键、在线假人查询、丢出物品、清空背包、幻翼生成开关，以及基岩/末地传送门框架点破开关。完整 **22 组主指令** 和参数都在 [命令手册](docs/全部命令.md)。

### 刷到想要的交易，而不是一直点刷新

独立刷交易筛选支持物品、附魔、药水效果、价格范围，以及多个交易序号：

- 内置 **331 钻石镐、附魔书、药水箭** 预设，中英文名称都能用。
- 可选基础价或当前价、等级恰好或至少、是否允许额外附魔/效果。
- 多个序号中任意一个命中就停，包含 Visible Traders 的高级交易预览。
- 可以手动停止，关闭交易窗口也会停止。只负责筛选，不替你买东西。

## 三步开始

想先看实际能怎么用？从这两个例子入手：[和平机一键开关、珍珠装置远程回家](docs/使用示例.md)。

下面三步适用于 **Windows / PCL**。其它启动器或系统请按[手动安装说明](docs/安装说明.md)选择所需模组；macOS 游戏运行尚未实测。

1. 在 [Releases](https://github.com/MIHUKUAKU/ms-tools/releases/latest) 下载 `MS-Tools-1.7.5-Windows-Setup.zip`，退出游戏并完整解压。
2. 双击 `开始安装.cmd`，选择存档并确认。**自动检测前置、安装工具、开启假人权限和脚本自动加载；旧文件备份，预设和交易链保留。**
3. 重进存档，输入 `/ms`。刷交易筛选的入口在村民交易窗口。

不用安装器也可以，见 [手动安装与排错说明](docs/安装说明.md)。Minecraft、Fabric Loader 和 Java 仍需要先在启动器里装好。

### 先试一个预设

```text
/ms add 1 alex 100.5 70 100.5 0 0 overworld
/ms keep 1
/ms list 1
/ms run 1
```

坐标是示例，请换成自己的。录入时可按 Tab 补全坐标和朝向。`keep` 只上线；`run` 右键后快速退出；想给机器留一点启动时间，用 `walk`。

## 版本与前置

目前适配 **Fabric 26.2 / 26.3**，需要 Java 25、Fabric Loader >= 0.19.3。

当前发布仅支持 Fabric；后续如完成 Forge 适配和测试，会在 GitHub 明确标注并提供对应版本。

| 功能 | 前置 |
| --- | --- |
| MS | 对应游戏版本的 Carpet，以及四个 Scarpet 脚本和 `mstrade` |
| 独立刷交易 | Fabric API、Trade Cycling >= 1.0.21、Visible Traders >= 2.5.0 |

不卡死第三方前置的小版本，但必须选对应 Minecraft 版本的文件。Gugle Carpet Addition 的假人背包界面可选，不是必须装的。

安装器配置好 Carpet 权限和脚本自动加载后，普通玩家使用 `/ms` **不需要 OP**，纯生存档不用先手动输入 `/script load`。联机时请注意权限，这些工具不适合直接开放给不信任的玩家。

## 使用前看一眼

- 自动移动适合提前整理好的平坦通路，不是通用寻路；避免障碍、悬崖和岩浆。
- 刷交易筛选目前只支持**单人存档**。村民需要绑定工作站且还没进行过交易；交易输入格和鼠标持物须为空。先等高级预览加载，再选序号。
- `clear` 是直接清空假人背包，不可撤销。特殊方块点破会直接移除方块，请谨慎开启。
- 两个版本均已编译通过；26.3 做过隔离运行和实际刷交易测试，作者最初在26.2实际使用时未遇到明显问题，另一次26.2隔离验证确认了客户端初始化。不是所有功能和边界条件都测过，详见 [测试记录](docs/测试报告.md)。其它 Minecraft 版本没有验证。
