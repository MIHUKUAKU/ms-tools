# MS 假人工具和刷交易筛选

一开始只是想让假人帮我开关和平机，每次输入一长串坐标和角度太麻烦，就把位置存起来，用编号调用。后来又加了搬东西、收集、合成潜影盒和村民交易，现在把这些功能整理出来。

这里有两个模组，可以分开装：

- **MS 假人工具**：主要用 `/ms`，管理 Carpet 假人和预设，让假人移动、取东西、放东西、交易等。
- **刷交易筛选**：这是另一个模组，在村民交易界面里按条件刷交易。不是 `/ms trade`，它只负责刷到想要的交易后停下来，不会自动购买。

## 怎么装

不想自己找前置的话，去 [Releases](https://github.com/MIHUKUAKU/ms-tools/releases) 下载 `MS-Tools-1.7.3-Windows-Installer.zip`。

1. 先退出游戏，重要存档最好自己也备份一下。
2. 把 ZIP 完整解压，双击 `installer/Install.cmd`。
3. 填 PCL 里具体的 Fabric 版本文件夹，选装 MS、刷交易，或者都装。装 MS 时还要选存档。
4. 再打开游戏，进存档输入 `/ms`。刷交易的按钮在村民交易界面里。

安装器会下载对应版本的前置，旧文件会备份，不会清掉你的预设和交易链。它不会帮你安装 Minecraft、Fabric Loader 或 Java，这些先在启动器里弄好。

具体步骤和出问题时看哪里，见 [安装说明](docs/安装说明.md)。源码放在发布附件的 `MS-Tools-1.7.3-Source.zip` 里，解压后的目录就是完整 Gradle 项目。

## MS 能干什么

- 给假人存位置和朝向，用编号召唤。`run` 右键后很快退出，`walk` 多留一会儿，`keep` 只上线不右键；也可以持续攻击或使用物品。
- 在自己或其他玩家的位置生成假人，把在线假人送到指定玩家那里。
- 控制移动、抬头低头和转向，查看在线假人的状态。
- 取面前箱子的东西、沿一排箱子取东西、按主手物品收集附近容器里的东西。有潜影盒时优先装盒，不会盒子套盒子。
- 把东西放回箱子，合成空潜影盒，或者丢出、清空假人物品。
- 按主手物品和村民交易，绿宝石块会自动拆开，盒子里的原料也能用。可以存交易链，也可以开 `keep` 等补货再交易。
- 关闭幻翼生成，或者开启点掉基岩和末地传送门框架的功能。这两个会影响世界，尤其是破坏方块，使用前注意一下。

所有命令、参数和例子都在 [全部命令](docs/全部命令.md)。

## 前置和版本

目前适配的是 **Fabric 26.2 / 26.3**，Java 25，Fabric Loader 至少 0.19.3。其它 Minecraft 版本没有验证，先别直接装。

| 要装的功能 | 前置 |
| --- | --- |
| MS | Carpet；完整功能要同时放好四个 Scarpet 脚本和 `mstrade` |
| 刷交易筛选 | Fabric API、Trade Cycling >= 1.0.21、Visible Traders >= 2.5.0 |

前置不限定到某一个小版本，但一定要选对应 Minecraft 版本的文件。Gugle Carpet Addition 的假人背包界面可以自己加，不是这里必须的前置。

普通玩家用 `/ms` 不需要 OP。安装器会设置 `commandPlayer true` 和脚本自动加载，所以纯生存档也不用先自己输入 `/script load`。联机时别直接装到不信任玩家都能用这些命令的服务器上。

## 先说明几个限制

自动走路不是完整寻路，最好给假人留一条平坦、没有障碍的路，也别让它靠近岩浆和悬崖。`clear` 是直接清空，不会把物品掉出来，也不能撤销。

刷交易筛选目前只支持单人存档。村民要有工作站，还没有进行过交易；输入格和鼠标上不要放东西。先等高级交易预览加载出来，再选序号。一次最多刷 10000 次，刷不到会停，不保证一定能出。

已经做了编译、后台检查和一些隔离存档测试，但没有把所有情况都跑完。哪些通过、哪些还没验证，写在 [测试报告](docs/测试报告.md) 里。原来的存档和个人预设没有放进发布包。

想自己改代码的话，看 [开发与兼容](docs/开发与兼容.md)。
